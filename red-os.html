для РЕД ОС — сертифицированное российское ПО

RuDesktop — российская программа удаленного доступа из реестра Минцифры РФ (№15913, №19573). Совместимость с РЕД ОС подтверждена официальным сертификатом соответствия. Поддержка корпоративных стандартов: TLS 1.3, AD/LDAP, SIEM.

Кому подойдет RuDesktop
на РЕД ОС?

Для системных администраторов

  • Управление серверами и рабочими станциями под РЕД ОС стало проще и удобнее благодаря централизованной панели управления и защите подключения. 
  • Удобное управление с помощью GUI и командной строки

Для бизнеса, корпораций и государственных учреждений

  • Создавайте защищенное подключение для сотрудников через удаленный рабочий стол, соответствующий требованиям информационных систем
  • Организуйте удаленную работу с полной защитой данных через RuDesktop для РЕД ОС

Для разработчиков и частных пользователей

  • Эффективная и безопасная работа с проектами через удаленный доступ на устройствах с РЕД ОС
  • Доступ к вашим устройствам на базе РЕД ОС — дома, на работе и в пути
